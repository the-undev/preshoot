# preshoot

Electron desktop app for storyboards and generation prompts. See
`docs/roadmap.md` for purpose, decisions and milestones, and
`docs/issues.md` for known bugs, limitations and improvements.

## Layout

- `src/main/` Electron main: window, protocol handler, service wiring.
- `src/main/core/` domain code. No Electron imports (lint enforced).
- `src/main/trpc/` router and context. Procedures call into core.
- `src/preload/` bridge only.
- `src/renderer/src/routes/` file-based TanStack routes. `routeTree.gen.ts`
  is generated; do not edit.
- `src/renderer/src/design-system/` the UI layer. `ui/` is shadcn output and
  is never edited; add components with `pnpm dlx shadcn@latest add <name>`
  and export them from `index.ts`.
- `resources/migrations/` Drizzle SQL, generated by `pnpm db:generate` after
  editing `src/main/core/db/schema.ts`. Commit the output.

## Commands

- `pnpm dev` runs the app with hot reload.
- `pnpm check` runs lint, format check, typecheck and tests. Run before
  handing over.
- `pnpm test` runs Vitest. Tests sit next to the code as `*.test.ts(x)`.
